# Microejemplo de lectura del diccionario

Cinco respuestas ficticias a un único ítem con categorías 1–4. El código 99 representa un dato perdido.

Ejecuta `Rscript --vanilla materiales/microcaso/01_microcaso.R` desde la raíz del taller. La primera media, 21.8, es una ejecución deliberadamente incorrecta en su interpretación de los datos. La segunda media, 2.5, usa cuatro respuestas válidas tras la recodificación documentada. Esta media solo ilustra el error; no valida un instrumento ni sustituye el caso factorial.

El script no necesita paquetes adicionales. La consola canónica se conserva en `salida_referencia.txt`.

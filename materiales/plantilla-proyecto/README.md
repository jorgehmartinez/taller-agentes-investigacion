# Plantilla de contexto de investigación para trabajar con un agente

Este conjunto mínimo ejemplifica cómo **integrar** un agente a un estudio, como si fuera un analista que se incorpora al equipo. Completa los documentos con información real del proyecto y revisa los permisos antes de compartir archivos.

## Archivos

- `AGENTS.md`: instrucciones persistentes; qué hacer, qué evitar y dónde buscar contexto.
- `docs/protocolo.md`: la pregunta científica, el diseño y las decisiones de investigación.
- `docs/diccionario.md`: semántica de los datos y de los instrumentos.

Un `plan.md` no es necesario de forma automática. Para tareas extensas o de alto riesgo, un plan de trabajo puede ser útil con pasos, criterios de revisión y aprobaciones. El contenido científico no debe repetirse íntegramente en `AGENTS.md`.

Esta plantilla **no** es un repositorio de código, un dataset, una skill ni una receta estadística. Incluye campos pendientes, no resultados. No pretende sustituir el conocimiento metodológico de los investigadores.

## Primer encargo de ejemplo

«Lee la documentación del estudio y explica los objetivos, las unidades de análisis, las variables disponibles, las decisiones analíticas que ya están establecidas y las lagunas que debo resolver. Todavía no modifiques archivos ni ajustes modelos».

## Adaptación

Cambia las referencias y permisos para el agente elegido. Mantén las credenciales fuera del repositorio. Cuando haya un proyecto de R real, incorpora rutas relativas, scripts reproducibles y un diccionario actualizado.

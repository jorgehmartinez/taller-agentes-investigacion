# Práctica: una carpeta recibida, no un proyecto preparado

`carpeta_recibida/` contiene únicamente seis archivos de entrada: dos PDF, dos bases CSV, un diccionario CSV y notas del equipo. No contiene AGENTS.md, instrucciones ocultas de agentes, scripts, resultados ni carpetas de análisis creadas de antemano.

El encargo científico es examinar la estructura interna y la fiabilidad de una escala ficticia de autorregulación académica. Los datos son simulados; el instrumento no es una escala validada. La organización del proyecto, la redacción de AGENTS.md y la selección de skills se realizan durante el taller.

## Preparar la sesión sin resolverla

Distribuir `caso_autorregulacion_inicio.zip`. Extraerlo en una carpeta vacía **fuera de este repositorio**, por ejemplo en una carpeta personal creada para el taller. Abrir en Positron exclusivamente la carpeta extraída `caso_autorregulacion/`, no la raíz del repositorio docente. El cliente puede heredar instrucciones de carpetas superiores o de configuración global: revisar ese contexto antes de comenzar, sin borrar ajustes personales.

No copiar la plantilla de AGENTS.md, los scripts de referencia o la carpeta docente al punto de partida. Conservar el ZIP para repetir la actividad. La copia de `carpeta_recibida/` versionada en Git es el original distribuible, no la carpeta de ensayo que debe modificarse en vivo.

## Inicio sugerido

Pedir al agente que inventaríe los archivos, lea el encargo y la documentación, distinga estudio principal y piloto y resuma objetivos y dudas. En ese primer paso no debe reorganizar, recodificar ni ajustar modelos. Después el grupo acuerda cómo trabajar y configura el proyecto.

Guion completo para el facilitador: `../docs/practica-guiada.md`. Comprobaciones y soluciones de referencia: `../docente/caso_autorregulacion/`, deliberadamente fuera del ZIP.
